# V5.15 — Resources Sample Read Contrast Fix

## Issue
The Sample Read resource card on `/resources` uses the `dark-card` surface. The global `.button` style also uses the site's navy background. Because the button inherited that dark treatment inside the dark card, the action text could become visually indistinct.

## Fix
Scoped the button styles to `.dark-card .button` so the action uses the site's light surface with navy text, with the existing accent used for hover/focus.

Also explicitly scoped the card heading, body text, and eyebrow colors so later global typography/theme changes cannot reduce contrast through inheritance.

## Accessibility target
Normal text should meet at least a 4.5:1 contrast ratio against its background under WCAG AA guidance. The explicit dark-card colors are intended to keep the component legible independent of inherited global styles.

## Scope
Only the Sample Read dark resource card is affected. Other buttons and resource cards retain their existing styling.
