# V5.18.7 remediation audit — 2026-10-15

## Issues addressed

1. **Manuscript deletion language:** Privacy, About, Team, and the request form now say the team confirms completion/deletion with the author, then deletes the manuscript and copies downloaded or created for the work.
2. **Reuse permission:** Public copy retains the explicit boundary that manuscript content will not be used, reproduced, published, or repurposed for another purpose without the owner's permission and approval.
3. **Privacy-page duplication:** Removed the repeated human-editorial/review-scope paragraph.
4. **Large-file transfer overclaim:** Removed language implying a secure alternative already exists. Both form copy and API response now say the form cannot accept files over 10 MB and that an appropriate transfer method must be discussed, not presumed available.
5. **Feedback-conflict tool mismatch:** The tool now applies simple keyword rules to each comment line in the browser and displays the entered lines in rough categories. It explains that results are heuristic, not AI, can be wrong, and are not a verdict. It tells users not to paste confidential manuscript text or identifying information.
6. **Release metadata:** Updated package name/version to `second-pair-editorial` / `5.18.7`; added this audit and the deletion SOP; updated README release and validation notes.

## Limitations not honestly representable as closed by source edits alone

- **Production build and full typecheck:** Not run; `node_modules` is absent in this environment. Syntax transpilation is not a production build or full typecheck.
- **Live Railway/email test:** Not run. Must be performed after deployment with a harmless test document and verified delivery.
- **Deletion in mailbox/provider systems:** The source code cannot delete mail attachments from the team's mailbox or control provider backups. `MANUSCRIPT-DELETION-SOP.md` defines the operational steps, but the business must verify the actual mailbox/provider deletion controls and follow the procedure on each completed project.
- **Persistent rate limiting:** Current limiter remains process-local/in-memory and is not durable across instances/restarts. Do not represent it as robust production-grade abuse protection; use a shared persistent store if this becomes a material threat.
- **Analytics:** A measurement specification exists, but no implemented analytics/funnel instrumentation was verified. Confirm the live setup before making acquisition decisions from metrics.
- **Dependency lockfile:** Still absent. Generate and commit the correct lockfile after a successful dependency install in the normal development environment.
- **Browser/accessibility behaviour:** Not browser-tested. Review mobile/desktop rendering, keyboard access, and the tool output with representative comments after build.

## Release decision

Source-level remediation is complete for the identified copy/tool/documentation gaps. This archive is **not certified as production-build or live-deployment verified** until the remaining environment-dependent checks above are run.
