# V5.20.2 — SEO fixes

- Removed the site-wide canonical from `app/layout.tsx` (it made any page without its own canonical point to the homepage).
- `/tools/reader-friction` and `/tools/feedback-conflict` now have their own title, description, canonical and OG tags (via a `layout.tsx` in each folder, since the pages are client components).
- New `config/seo.ts` → `withSeo(meta, path)` adds canonical + Open Graph + Twitter (including the share image) to a page. Applied to all indexable pages, problem, service and start pages. Previously child pages that set `openGraph` lost the og:image.
- `config/site.ts`: a production build now fails if `NEXT_PUBLIC_SITE_URL` or `NEXT_PUBLIC_CONTACT_EMAIL` is missing, instead of publishing localhost URLs. Trailing slashes on the URL are stripped.
- `app/sitemap.ts`: problem, service and start URLs are generated from data (problem data moved to `config/problems.ts`); the fake `lastModified: now` is removed.
- Logos use `next/image` (width/height set, WebP/AVIF, header logo prioritised).

- v5.20.2 deploy fix: typescript and @types/* moved to `dependencies` so hosts that install with NODE_ENV=production (npm --omit=dev) can type-check during `next build`.
- Homepage: contact email line added under the final call to action (reads NEXT_PUBLIC_CONTACT_EMAIL).
- Sample-request API: env values are trimmed (stray spaces/newlines/quotes from pasted host variables broke the Resend call with a 500); Resend network failures return a clear 502 and are logged; a failed confirmation email can no longer turn an already-delivered request into an error.
- Sample-request API: removed `instanceof File` (Node 18 has no global File, so every submission threw a 500). `engines` now requires Node >=20 and `.nvmrc` pins 20.
- Added Google Search Console verification meta tag (root layout metadata).
- Performance: `next.config.mjs` enables `experimental.inlineCss` so the stylesheet no longer blocks first paint (local Lighthouse mobile: performance 0.82 -> 0.99, render-blocking and network-dependency-tree insights now pass). The remaining "legacy JavaScript" hint (~12 KiB) is Next 15 core runtime and is not removable via config.
- Accessibility: text colour contrast fixed site-wide (WCAG AA 4.5:1). `--accent-dark` is now #7a5b2b and used for gold text on light backgrounds; `--muted` is now #5f6672; the original gold stays for borders, fills and text on navy. Verified with Lighthouse on all 59 sitemap pages, mobile and desktop.
- Video checklist pass: custom 404 (`app/not-found.tsx`, noindex) and error pages (`error.tsx`, `global-error.tsx`); share image + canonical on the five beta-reader guide pages; square favicons (`app/icon.png`, `apple-icon.png`, `favicon.ico`) replacing the non-square logo; meta descriptions trimmed to ~158 chars at a word boundary.
