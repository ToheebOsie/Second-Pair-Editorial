# V5.20.0 — Cookie consent and analytics gating

## Changes
- Added a responsive consent banner with Accept all, Reject optional, and Cookie settings.
- Google Analytics `G-RB9DS44MBZ` is only loaded after affirmative analytics permission.
- Stored the visitor's choice in browser local storage and added a persistent footer link for revisiting settings.
- Added a preferences panel and a privacy-policy explanation of optional analytics.
- Removed the unconditional Google Analytics loader from the root layout.

## Verification notes
- Static source checks confirm the Google tag loader is only in the consent manager and is called only on an affirmative choice or a previously saved affirmative choice.
- A production build and live browser/Google Analytics verification remain necessary before release.
- This lightweight implementation is not a certified third-party CMP and should be checked against legal requirements for target jurisdictions.
