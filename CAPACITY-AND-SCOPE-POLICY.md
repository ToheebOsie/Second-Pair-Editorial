# Second Pair — Capacity and Scope Policy

## Purpose

Protect quality as the business moves toward premium engagements.

## Capacity states

### OPEN
New work can be accepted after normal review.

### LIMITED
Only projects that fit the available editorial capacity are accepted.

### WAITLIST
The work appears suitable, but the next responsible start window is later.

### CLOSED
No new work is accepted until capacity reopens.

## Rules

1. Never invent scarcity.
2. Never promise a start date before checking capacity.
3. Never accept a larger scope merely because the client can pay for it.
4. Prefer a smaller sufficient route when it answers the question.
5. Protect enough time for manuscript reading, reasoning, QA and delivery.
6. Record scope changes before additional work begins.

## Premium-quality floor

A project should be declined, delayed or narrowed when accepting it would materially reduce:

- reading depth;
- evidence checking;
- report quality;
- communication quality;
- agreed delivery reliability.
