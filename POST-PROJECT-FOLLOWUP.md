# Second Pair — Post-Project Follow-Up

## 48–72 hour window after delivery

Ask:

- Did the work answer the question you came in with?
- Is anything unclear?
- Did the findings help you decide what to do next?

Do not ask for a testimonial in the same breath as a problem-resolution request.

## Later follow-up

Use the manuscript's actual stage to determine whether a follow-up is useful.

### If diagnostic
Offer clarification or revision planning if requested.

### If developmental
Offer a revision-review path only when the author has completed meaningful changes.

### If revision review
If the manuscript is now stable, explain the possible next precision stage without assuming it is needed.

### If precision editing
If the work is at final stage, proofreading may be relevant.

## Referral/case study

Ask separately and only after the client has had an opportunity to evaluate the work. Obtain explicit permission before publishing identifying material.
