# Inquiry Review Checklist

Use this before replying to a new author inquiry.

## A. What did the author actually ask?
- [ ] I can state the author's main concern in one sentence.
- [ ] I have separated the author's concern from the service name they selected.
- [ ] I know whether they want reader reaction, diagnosis, revision help, prose editing, or final correction.

## B. What do we know?
- [ ] Manuscript title
- [ ] Genre
- [ ] Word count
- [ ] Manuscript stage
- [ ] Relevant sample or manuscript available
- [ ] Author's specific concern
- [ ] Previous feedback or revision history, if relevant

## C. What do we still need?
Ask only for information that could change the scope or recommendation.

- [ ] Missing manuscript/sample
- [ ] Missing word count
- [ ] Missing project stage
- [ ] Unclear concern
- [ ] Unclear desired deliverables
- [ ] Previous draft/feedback needed for a revision review

## D. Routing check
- [ ] Is Alpha Reading enough?
- [ ] Is Beta Reading enough?
- [ ] Is a Manuscript Diagnostic more appropriate?
- [ ] Is Developmental Editing actually needed?
- [ ] Is Revision Review the real question?
- [ ] Is Line Editing enough?
- [ ] Is Copy Editing enough?
- [ ] Is Proofreading enough?
- [ ] Does the project genuinely require several stages?

## E. Before quoting
- [ ] Scope is clear.
- [ ] Deliverables are clear.
- [ ] Price basis is clear.
- [ ] No unconfirmed turnaround has been promised.
- [ ] Anything outside scope has been identified.

## F. Reply quality
A good reply should:
- acknowledge the author's actual concern
- show that we understood the manuscript stage
- explain the proposed next step in ordinary language
- avoid diagnosing unseen pages
- avoid unnecessary sales language
- make the next action obvious

## Red flags
Do not:
- promise that a manuscript will become publishable
- promise sales or publication results
- call a manuscript “bad” from a short description
- recommend the most expensive service just because it exists
- use “brutal honesty” as a selling point
- invent urgency
- offer discounts that were not approved
- imply that a sample read guarantees a booking
