# First-12 Production Content Cluster — V5.10

This folder turns the first twelve canonical problem pages into a production content system.

## Contents
- `newsletters/` — 12 complete newsletter issues
- `long-form/` — 12 complete long-form article drafts
- `social/` — 120 derivative prompts (10 per canonical problem)

## Editorial rule
The public content must answer the author's question before mentioning a service. The content should demonstrate diagnosis, not merely repeat writing advice.

## Source discipline
The craft lenses are synthesized from the supplied professional corpus. They are not presented as universal laws, and no source passage is reproduced.

## Conversion discipline
Every piece routes back to the canonical problem page. The problem page is the bridge to a diagnostic/tool where one exists, and to professional inquiry only when the question requires manuscript-level judgment.


## V5.12 voice-audit rule
Do not reuse a fixed article skeleton. Reuse the diagnostic method, but make the reasoning, evidence test, examples, and professional threshold specific to each problem.
